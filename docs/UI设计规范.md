# 运营工作台 UI 规范

版本：V2.1.0-beta.3，2026-10-23。采用用户确认的 Tabler 白底、蓝色主色、细边框和紧凑表格方向。

## 文件分工

| 文件 | 用途 |
| --- | --- |
| `assets/vendor/tabler-1.7.0.min.css` | 固定版本的 Tabler Core 基础样式，原样保存，无外部字体或CDN请求 |
| `assets/vendor/tabler.LICENSE` | Tabler MIT 许可 |
| `assets/legacy-layout.css` | 从原HTML搬出的历史分析布局，保留既有业务展示 |
| `assets/ui-theme.css` | 项目共用设计变量、组件样式及响应式规则；后续新增UI优先复用这里 |
| `assets/ui-workspace.js` | 导航、搜索、列视图、只读详情、看板展示和键盘交互，不写业务数据 |
| `assets/user-import-ui.js` | 上传预览和预警交互；保留原受控确认流程，预警改为右侧抽屉 |

Tabler来源：npm `@tabler/core@1.7.0`，发布包完整性在下载时核验SHA-512。CSS未更改，所有项目覆盖在主题文件中。无需运行时请求第三方CDN。

## 视觉约定

- 主色 `#206bc4`，页面底色 `#f6f8fb`，正文 `#182433`，边框 `#e2e8ef`，常用圆角6px。
- 白色侧栏、顶部面包屑、白色卡片、统一线框图标。主要动作使用蓝色按钮，普通动作使用描边按钮。
- 统一系统中文字体，恢复标准鼠标指针；表格数字右对齐，不用颜色暗示未发生的数据变化。
- 国家和普通标签使用低饱和中性色；下单中蓝色、待下单灰色、已流失深灰、流失又回绿色；异常使用淡橙提示。
- 页面间复用按钮、输入框、筛选器、表格、抽屉和表单。新增组件应补入主题文件，避免在页面中重复添加整套内联样式。

## 名单视图

默认8列：转化CAM、商品标题、国家、负责人、转化跟踪、转化下单量、支付订单、最近下单日期。CAM固定在左边，详情入口固定在右边，其他列允许表格内部横向滚动。

列设置可以选择全部27个业务字段；CAM不可隐藏。列顺序优先常用字段，再按原业务字段顺序补齐。选择仅存本浏览器的 `order_project_ui_columns_v1`，不修改数据库记录，不影响同事的视图。

搜索匹配CAM、业务用户ID、注册邮箱和商品标题，与年份及字段筛选同时生效。清空筛选会清空关键词和字段筛选；月份折叠及列偏好分别维护。预警定位会清除关键词，避免对应CAM被搜索隐藏。

详情抽屉展示全部字段，只读；“在表格中查看全部字段”打开完整列视图，仍按现有权限决定哪些字段能编辑。隐藏列不清空数据，TSV导出始终使用当前完整筛选结果和全部业务字段，分析统计也不按可见列截断。

## 看板与预警

看板突出转化CAM、累计下单量、累计支付订单和待处理预警；前3项受看板筛选控制，预警明确显示整个工作区的待处理记录数。原日均订单、去重用户和流量效率可展开查看，原计算口径保持。

广告位与转化月份支付汇总使用现有实际数据；不把累计快照画成“每日新增订单趋势”。效果图的演示数值不进入产品。

预警使用右侧抽屉，含分类数量、待处理列表及新旧值对照。确认、忽略、只读权限、并发版本保护和硬错误不可确认沿用原逻辑。分类计数为记录数，顶部名单警铃仍按原规则统计待处理CAM/记录，两处口径分别保留。

## 交互与验证

桌面侧栏常驻，720px及以下收起为菜单；表格在容器内滚动，页面不被宽表撑开。提供按钮文字、输入框标签、焦点边框；新列设置和详情支持Escape、Tab焦点限制及关闭后返回触发位置。预警支持Escape和遮罩关闭；浏览器原生确认仍保留。

本轮验证覆盖：27项原规则与映射、9组Chromium模拟Auth/REST集成场景、1586px桌面及390px手机布局检查。测试包括列偏好刷新恢复、组合筛选、隐藏列完整导出和已有云端保存/上传/预警流程。未更改数据库结构、RLS、RPC或真实业务数据；两个真实账号协作和真实网页上传仍属于后续验收。

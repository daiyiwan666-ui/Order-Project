# 转化用户名单 V2.0：文件导入与每日订单更新

日期：2026-10-14。当前业务规则以本说明及《转化用户名单_文件导入需求记录》为准；截至V1.9的docx保留为历史版本。

## 1. 实现范围

新增上传入口、工作表/编码选择、分页预览、按广告id新增CAM、每日累计订单更新、派生状态与持续出单区间计算、异常预警及人工确认。现有人工编辑、筛选、年份月份分组和导出继续使用。未实现删除或外部定时抓取。

新增逻辑拆到 assets/user-import-core.js（纯规则）和 assets/user-import-ui.js（页面交互）；原有分析仍在index.html。SheetJS 0.18.5及许可证在assets/vendor，运行无需npm安装或在线CDN。

## 2. 解析与字段

支持xls/xlsx/xlsm/xlsb及模板文件、csv/tsv、ods。单文件32MB以内；CSV可选UTF-8或GB18030。自动优先选择包含广告id/转化CAM表头的工作表，也可手选。识别表头以上的说明行，不执行单元格指令或公式代码。

映射只用明确的一对一关系，支持源字段名或者程序标准字段名；重复列和同一目标的双来源会拒绝整份工作表。广告id、用户ID、两个订单总数、最近下单时间、是否流失和流失日期是必需列；单元格能否为空按行校验。

ID保持文本，数值型不安全长整数需修正文件。Excel序列日期支持1900/1904系统；日期内部按业务墙钟时间放在UTC槽位，不因运行电脑时区偏移日期。最后编辑时间使用Asia/Shanghai，保留秒。

标签拆分去掉方括号，归一并去重。转化相关标签进入转化原因，已知负责人进入负责人；负责人默认唐华、庞遵毅，并补充名单中已有负责人。其他未识别标签不会被当成人名；业务明确忽略的标签不导入。人工转化备注不从标签提取。

## 3. 更新计划与确认

先生成计划，不修改数据。新CAM填入映射信息；已有CAM仅替换最近下单日期、转化下单量、支付订单、是否流失、流失日期。累计值替换，不累加。转化日期及人工字段不会被日更覆盖。

相同CAM的完全相同源记录合并；冲突重复记录全部暂缓。每行结果为新增、更新、无变化、待确认或需修正。预览每页50行。

正常记录保存后刷新看板和分析；异常记录暂缓整行更新。可复核的订单回退、下单时间回退、支付大于下单提供确认；无效订单值、CAM归属冲突、缺失关键日期、矛盾日期、互斥原因等只能修正重传。

确认更新时再次比较CAM及原订单/日期/流失数据，拒绝已过期候选；应用时从当前行取人工字段，防止确认旧快照覆盖后续人工备注。确认更新及预警状态变更一起写入，保存失败不部分生效。

新的正常更新替代同CAM的旧待处理候选。重复异常通过指纹去重；忽略本次不写入候选。无法从最近下单时间推断文件实际生成日期，系统不自动假定某个文件一定较新。

## 4. 状态及计时

未流失且下单量为0为待下单，否则有效非零下单量为下单中。是否流失为yes时，最近下单日期在流失次日或以后才为流失又回；同日仍为已流失。转化跟踪为只读系统字段。

持续出单状态结构：version、periods（已结束区间）、activeStart、estimated、lastStatus。订单从0开始发生时记录最近下单时间为固定起点，后续订单时间更新不重置。流失关闭区间，回流开启新区间，跨越两种状态的单次上传也会关闭旧区间再恢复。先人工标记流失再补日期时保留原计时起点。

首次导入及旧缓存迁移使用转化日期作为历史估算起点；待下单不计时，支付为0不阻止计时。初次看到流失又回仅能根据当前流失日期及最近下单时间估算，不能还原全部历史周期。

时长以有效区间毫秒数相加后向下取完整天数。动态显示每分钟刷新名单（编辑或筛选弹窗打开时不打断操作），动态时间显示不改变最后编辑时间。TSV导出使用同一计算值，并正确转义制表符、引号和换行。

## 5. 预警入口与本地保存

原右上角流失待分析警铃为统一入口，分类为异常订单、数据异常、流失待分析。多类时显示异常预警中心。角标按CAM去重，空CAM的错误按源记录计数。查看使用原年份/月分组/筛选清除/滚动高亮逻辑，不视为批准。

tdfx_workspace_v20保存version、users、continuous和alerts的统一快照。一次localStorage写入成功后再替换内存数据；配额不足不部分更新。已在其他窗口变化的快照会提示刷新，不覆盖。

旧名单tdfx_users_v14只读迁移，验证CAM非空、唯一且编号精度安全，不限制样例行数。旧计时键tdfx_continuous_v1不改写，新口径重新生成历史估算；旧存储保留。订单页和国家颜色缓存继续沿用原键。损坏的新快照阻止保存，不自动覆盖旧数据。

最后编辑时间、年、季度、持续出单时长及转化跟踪为只读派生字段；是否流失为单选。其余标签维持原有交互。最近下单周及流失监控系统从可见字段/筛选/导出移除，历史数据属性不破坏性清除。
